
# Machine Learning Fundamentals for Aviation

## Flight Delay Prediction Using Machine Learning

This course activity demonstrates a simple *Machine Learning* classifier for flight delay prediction using a small, fictional dataset. Students will modify the input features using real-world flight information and observe the model’s predictions. The exercise illustrates the basic classification workflow and highlights the limitations of models trained on synthetic data.

### Objective

Use a Decision Tree Classifier to predict whether a selected flight will be delayed or depart on time.

### Tasks

1. Select a flight: Choose a flight operated by an airline serving an international airport. Record its flight number, and scheduled departure time.
2. Research the conditions: Identify the expected weather conditions and the congestion level at the departure airport. Record your information sources.
3. Update the Python script: Enter the flight code and modify the three input features: `Hour`, `Weather`, and `Congestion`.
4. Run the model: Execute the script and observe the prediction.
5. Gather the results file: The prediction is save automatically in a `prediction.txt` file.

### Deliverables

Upload in the Moodle assignment an archive containing:
* The modified Python script (`classifier.py`).
* The prediction file (`prediction.txt`).

Important: This is an educational demonstration using synthetic data. The model’s output must not be interpreted as a reliable prediction of actual flight operations.
